# Daily Do

`daily-do` is a React-based application with frontend source files and package metadata for local development.

## Features

- React-based frontend with a local development workflow

## Tech Stack

- React
- Vite

## Project Structure

- `.gitattributes` - project file

## Getting Started

### Prerequisites

- Node.js 18+

### Setup

```bash
git clone https://github.com/ENZOMOTIVE/daily-do.git
cd daily-do
```

```bash
cd dailydo
npm install
npm start
```
